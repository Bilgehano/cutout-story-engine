# AGENTS.md — Workspace Constitution

Read this file completely at the start of every session. Also read `.github/skills/cutout-animator/SKILL.md`. These rules are mandatory. Everything in this repository (docs, prompts, code, comments, JSON schemas, CLI logs) is written in English. Video content (dialogue, subtitles, voiceover) is written in the selected video language.

## 1. Architecture

- 100% code-driven, modular **React + SVG cut-out puppet animation** in **Remotion**.
- Format: **1080x1920 vertical 9:16, 30 FPS**.
- Characters are layered SVG `<g>` groups in `src/components/characters/`; environments are layered SVG components in `src/components/backgrounds/`. Both are registered in their `index.ts` registry and in `story-bible.json`.
- External generative image/video APIs (fal.ai, Midjourney, Kling, Runway, Sora, Pika, DALL·E, Stable Diffusion, etc.) are **strictly forbidden**. Only ElevenLabs (voice) is an allowed external API. Do not import raster art generated by AI.
- Key files: `src/EpisodeComposition.tsx` (timeline), `src/PreviewComposition.tsx` (QA stills), `src/Root.tsx`, `src/components/types.ts` (shared contracts), `src/components/Subtitle.tsx`, `src/data/draft_script.json` (input), `src/data/episode.json` (generated), `story-bible.json` (canon).

## 2. Audio-First Principle

Never guess scene durations. For every dialogue line, in this order:

1. Generate the ElevenLabs voiceover first (mp3).
2. Convert to 16 kHz mono WAV with FFmpeg.
3. Extract visemes with Rhubarb Lip Sync (`bin/rhubarb` or `bin/rhubarb.exe`).
4. Measure the exact duration with `ffprobe`.
5. Compute `durationInFrames = Math.ceil((durationSec + 0.25) * 30)`.

`node .github/skills/cutout-animator/scripts/produce.mjs` performs all steps. Never hand-write durations or mouth cues in `episode.json`.

## 3. Art Direction

- Flat-shaded amateur stick figures are **forbidden**.
- Follow every reference image in `refs/` (proportions, palette, line quality). If `refs/` is empty, still meet the quality bar below.
- Consistent `3px #1E1B18` outlines on all shapes (round joins and caps).
- Subtle gradients: cheek blush, neck/jaw shadow, cloth folds, ambient occlusion under props.
- Layered hair with multiple tufts and tonal variation; no single-blob hair.
- Cinematic, harmonized color palettes per environment and `timeOfDay` (`day`, `sunset`, `night`) with light overlays and vignettes.
- Characters must stand on the floor line (`y = 1480`) or sit on the seat line; depth is built with `back`, `mid`, `characterSlot`, `foreground` layers.

## 4. Mandatory Visual QA

After generating or modifying **any** character or environment SVG, you MUST render a PNG using `npx remotion still` into `out/` and visually inspect it before finishing. Examples (see SKILL.md §9):

```bash
npx remotion still Preview out/char_<Name>_check.png --props="{\"characterId\":\"<id>\"}"
npx remotion still Preview out/bg_<Name>_check.png --props="{\"environmentId\":\"<envId>\",\"characterId\":\"<id>\"}"
```

If the render reveals problems (misaligned face, clipped limbs, wrong layering), fix and re-render until clean. Never report a visual task as done without having looked at the PNG.

## 5. Language & Localization

- `story-bible.json` contains `defaultLanguage` (ISO 639-1, the channel default) and `voiceProfiles` (per-language default ElevenLabs voice IDs). Characters may carry `voices: { "<lang>": { "voiceId": "..." } }`.
- Each episode may override the language with `languageCode` (ISO 639-1, e.g. `en`, `de`, `tr`, `es`, `fr`) in `src/data/draft_script.json`. If absent, use `defaultLanguage`.
- The chosen language governs: script dialogue, subtitles, and the ElevenLabs request (`model_id: "eleven_multilingual_v2"`, `language_code`).
- Write natural, native-quality text with correct diacritics. Never mix languages inside a line unless the story requires it.
- Rhubarb uses the `phonetic` recognizer for non-English languages (handled by `produce.mjs`).

## 6. Workflow Commands

| Command | Purpose |
|---|---|
| `/setup` | Check dependencies (Node, FFmpeg, Rhubarb), ask for channel language and default voice, initialize the project and config files. |
| `/character` | Interactive Q&A (6 questions), then build, register, and visually verify a new character. |
| `/environment` | Interactive Q&A (4 questions), then build, register, and visually verify a new environment. |
| `/video` | Write the draft script in the chosen language, run the audio-first pipeline, render the episode MP4. |
| `/review` | Verify the MP4 with `ffprobe`, validate `episode.json`, render QA stills, report, and update the story bible. |

Prompt files live in `.github/prompts/`. Phase 1 of `/character` and `/environment` is Q&A only: do not write code until the user has answered.

## 7. Engineering Rules

- TypeScript strict mode; import shared types from `src/components/types.ts`. Do not duplicate them.
- Animation is deterministic: derive everything from `useCurrentFrame()`. No `Math.random()`, no CSS transitions, no timers.
- Use `interpolate` (always clamped) and `spring` per SKILL.md.
- No TODOs or placeholder stubs; every file must be complete and runnable.
- Never commit `.env`, API keys, generated audio, or lip-sync files (`.gitignore` covers them).
- Keep comments minimal; only explain non-obvious logic.
- Do not modify `src/data/episode.json` by hand; it is generated.
